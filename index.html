Keygate

Capability-based access control for Soroban: capability registry, policy rules, a latching circuit breaker and m-of-n multisig relay.

View on GitHub TeethakingBuilds

How it fits together

1. Contracts hold capabilities and policy rules on-chain.
2. Server mirrors capabilities from Soroban events and answers authorisation queries, failing closed.
3. Client builds calls, signs authorisations, and verifies a server decision before trusting it.
