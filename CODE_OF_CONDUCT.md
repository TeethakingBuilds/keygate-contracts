# Contributor Covenant Code of Conduct

## Our pledge

We aim to keep keygate welcoming for whoever shows up to work on it: integrators
putting it in front of real value, people fixing a typo in a doc, and anyone
reviewing a change before it merges. Participation here is a volunteer activity,
which makes courtesy the whole of what we owe each other.

This document is adapted from version 2.1 of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behaviour

- Assume the person wrote the code or comment in good faith, and say so in
  review rather than by silence.
- Critique the change, not the author. "This branch leaks when `used` is
  negative" is useful; "why would you do this" is not.
- Accept that a maintainer can decline a change. A "no" on a pull request is a
  decision about this project, not a judgement of the contributor.
- Take disagreement to a private channel if it stops being about the code.

## Unacceptable behaviour

Harassment of any kind, personal or political attacks, publishing something
private that was shared in confidence (including a vulnerability report), and
sustained disruption of discussion.

## Reporting

keygate is maintained by one person, so "report it to the maintainers" means
report it to the maintainer, and the only private channel GitHub gives a project
like this is a security advisory: use **Security → Report a vulnerability** on any
keygate repository, even when the matter is conduct rather than code. A draft
issue works if the incident is public knowledge already. Reports are kept
confidential as far as the project can keep them; the reporter's identity is
never published.

The first response to any report is that it was read. The range of responses is
a warning, a request to withdraw a comment, a temporary ban, or a permanent ban
from the repositories — chosen for what stops the harm, not for what punishes.

## Attribution

This code of conduct applies to all keygate repositories

[keygate-server](https://github.com/TeethakingBuilds/keygate-server),
[keygate-client](https://github.com/TeethakingBuilds/keygate-client)) and to any
